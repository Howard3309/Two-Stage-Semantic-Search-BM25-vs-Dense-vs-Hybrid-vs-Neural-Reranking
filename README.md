# Two-Stage Semantic Search: BM25 vs Dense vs Hybrid vs Neural Reranking

## Problem
Given a natural-language query, retrieve the most relevant documents. This project compares classical lexical search, dense retrieval, hybrid fusion, and cross-encoder reranking on a public benchmark.

## Pipeline
1. **First stage:** BM25 (lexical), bi-encoder + FAISS (dense), and Reciprocal Rank Fusion (hybrid)
2. **Second stage:** cross-encoder rerank of the top 50 candidates
3. **Evaluation:** NDCG@10, MRR@10, Recall@100, latency (ms/query)
